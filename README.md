# MaxTrak

A native iOS app for tracking strength training maxes, built with SwiftUI and SwiftData.

## Features

- **Exercise grid** — log lifts as cards, auto-sized relative to your strongest max, with a native zoom transition into detail view
- **Training goals** — tag each lift as Endurance, Hypertrophy, or Strength; suggested working sets adjust their %1RM and rep-range targets accordingly
- **Progress tracking** — full max history per exercise plus a Swift Charts line graph of estimated 1RM over time
- **Plate calculator** — interactive barbell loader with live total, auto-load to any logged max, and color-coded over/under/match comparison
- **Light/dark theme** — adaptive color system with an in-app override in Settings
- **Edit mode** — long-press any card to jiggle and delete, iOS-homescreen style

## Stack

- Swift / SwiftUI
- SwiftData for persistence
- Swift Charts

## Requirements

- iOS 18+
- Xcode 16+
